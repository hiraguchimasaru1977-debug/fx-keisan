# FX計算ツール

FXの計算をまとめてできる、無料の日本語Webツールです。

**公開ページ：https://fx-keisan.netlify.app/**

## できること

- 売買の損益計算（手数料・スワップ込み）
- 必要証拠金・証拠金維持率・ロスカットの目安
- 許容損失から逆算する適正ロット
- 損切り・利確価格の自動計算
- 勝率とリスクリワードからの勝敗シミュレーション（モンテカルロ法）
- 取引記録（資産管理）、月別集計、CSVでの保存・読み込み

## 特徴

- インストール不要。ブラウザだけで動きます
- スマホ対応
- 取引記録はブラウザ内だけに保存（サーバーには送りません）

## ファイル

- `index.html`：ツール本体（1ファイルで動きます）
- `robots.txt`、`sitemap.xml`：検索エンジン向けの設定

※ 本ツールは参考計算用であり、投資助言・利益保証ではありません。
